About

How this site works

Cosmos is a small astronomy guide built with nothing but HTML, CSS and JavaScript. No frameworks, no build step, no internet connection. Open the folder, double-click a page, and it runs.

🎨

Every planet is CSS

There isn't a single image file in this project. Jupiter's bands are a repeating gradient, Saturn's rings are a rotated ellipse made from a border, and the shading that makes each planet look round is an inset shadow.

📐

Constellations are geometry

Each star pattern is stored as a list of coordinates and a list of which stars to join. The SVG is generated from those numbers, so the shapes stay sharp at any size — and the dot sizes match real star brightness.

🌙

Moon phases are calculated

No lookup table and no API. The code knows the date of one new moon in the year 2000 and the length of the lunar cycle, and works out everything else with arithmetic.

Structure

What's in the folder

Six pages, one stylesheet, five scripts. Every file has one job.

  • index.html · planets.html · constellations.html · moon.html · facts.html · about.html

    The six pages. Each one holds only its own content — the shared header, footer and starfield are repeated in each file so that every page works on its own, with no server required.

  • css/style.css

    One stylesheet for the whole site, split into numbered sections. All colours and sizes are defined once at the top as CSS variables, so the entire theme can be changed from about twenty lines.

  • js/starfield.js

    Draws the moving night sky on a canvas: roughly a thousand stars in three depth layers, twinkling at different speeds, drifting as you scroll, with the occasional shooting star.

  • js/main.js

    The behaviour every page shares — the mobile menu, highlighting the current page in the nav, fading sections in as you scroll, and the rotating fact on the home page.

  • js/planets.js · js/constellations.js · js/moon.js · js/facts.js

    One script per section. Each stores its content as an array of data at the top, then builds the page from it. Changing a fact means editing one line, not hunting through HTML.

Sources & limits

Where the numbers come from

Planet data

Diameters, distances, orbital periods, gravity and temperatures follow NASA's planetary fact sheets.

Moon counts change

Moon totals are confirmed moons and genuinely move. Saturn gained 128 in 2025 alone, overtaking Jupiter. Any number you see quoted has a date attached to it, whether or not it's stated.

The phase maths is approximate

The moon calculation assumes a perfectly even 29.530589-day cycle. The real orbit speeds up and slows down slightly, so results can be a few hours out. Fine for the naked eye; not good enough to land a spacecraft.

Constellation maps are simplified

Star positions are plotted to look right rather than to catalogue precision, and only the main stars of each pattern are drawn. Real constellations contain far more stars than the ones joined by lines.

Sizes, not distances

The true-scale switch on the planets page resizes the planets correctly, but the gaps between them are still nothing like real. Space is mostly emptiness, and emptiness doesn't fit on a screen.

Nothing is tracked

No analytics, no cookies, no accounts, no network requests of any kind. The only links that leave this site are the ones in the footer, and they are clearly marked.

Make it yours

Change something

Open css/style.css and change --teal at the top of the file to any colour you like. Save, refresh, and watch it ripple through every page at once. That's the whole reason those variables are there.
